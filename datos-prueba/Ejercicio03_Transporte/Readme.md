# Datos de ejemplo de Transporte

`datos/viajes.txt` y `datos/boletos.txt` deben estar en la misma carpeta para importarse. Se corrigio la ubicacion del archivo de boletos, que antes estaba dentro de `datos/datos`.

Hay cuatro viajes y tres boletos, uno anulado. Los asientos ocupados corresponden a los dos boletos activos. Las salidas son en enero de 2027.

Consulte [las instrucciones de Transporte](../../src/Ejercicio03_Transporte/README.md) para copiar el ejemplo a una carpeta temporal y ejecutarlo. El programa importa TXT y guarda sus cambios posteriores en un unico archivo JSON.
