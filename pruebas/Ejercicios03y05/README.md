# Pruebas de Transporte y Artesanias

Ejecutar desde la raiz:

```powershell
dotnet run --project pruebas/Ejercicios03y05 -- pruebas/Ejercicios03y05/RESULTADOS.md
```

El programa termina con codigo 0 si todos los casos pasan y 1 si hay fallos. No requiere paquetes de pruebas externos. RESULTADOS.md se genera a partir de la ejecucion real. Los archivos temporales se eliminan al finalizar.

Cobertura: tarifas y descuentos; rutas y fechas; disponibilidad y anulaciones de asientos, incluido el limite exacto de dos horas; cinco reportes de transporte; TXT heredados, JSON y cambio de cultura; recepciones y ventas FIFO; stock; propiedad y devoluciones; comisiones y liquidaciones; noventa dias; rankings; periodos; integridad de referencias; fallos de escritura y conservacion de memoria; arranque, salida, EOF, entradas invalidas y consultas a traves de ambos menus.

Tambien se ejecutaron las pruebas existentes de Biblioteca (13), Cooperativa (48) y Cafeteria (8), todas correctas. Este resultado cubre los casos disponibles y los agregados; no sustituye pruebas para futuros cambios.
